# เริ่มแชตใหม่กับ ChatGPT (ใช้ทุกครั้งที่เริ่มตัวละครใหม่)

## ขั้นตอน
1. เปิด **แชตใหม่** (1 ตัวละคร = 1 แชต)
2. แนบไฟล์ 2 อย่าง: `docs/card/card_template_guide.png` (ผังการ์ด) + ภาพอ้างอิงตัวละคร (ถ้ามี)
3. วางข้อความ **ข้อความเปิดแชต** ด้านล่างทั้งก้อน
4. ได้สเตจ 1 ที่ชอบแล้ว ตอบว่า "ผ่าน ล็อกเป็นต้นแบบ" แล้วค่อยขอสเตจ 2, 3, 4 ทีละภาพ
5. ภาพไหนเพี้ยน → พิมพ์ "เจนใหม่จากต้นแบบสเตจ 1" อย่าสั่งแก้ทับภาพที่เพี้ยน
6. ดาวน์โหลดด้วยปุ่มดาวน์โหลดบนภาพ ไม่แคปหน้าจอ

---

## ข้อความเปิดแชต (ก๊อปทั้งก้อน)

```
คุณคือนักวาดตัวละครของเกม dark fantasy RPG แนว bara 18+ ทุกภาพต้องทำตามนี้

[สไตล์]
dark fantasy painterly illustration, hand-painted look, soft natural skin,
hair painted in clean directional strands, body hair only where natural,
muted earthy colors, moody rim light, clear readable shapes.
ห้าม: hyper-realistic, 3D render, plastic shine, ลายพื้นผิวซ้ำๆ บนผิว ผม ขน หรือโลหะ

[ไฟล์]
- 1024×1536 แนวตั้ง PNG พื้นหลังโปร่งใสจริง (ห้ามลายตารางหมากรุก ห้ามสีดำ/ขาว)
- ตัวละครคนเดียว เต็มตัวหัวจรดเท้า ไม่มีตัวหนังสือ โลโก้ กรอบ หรือฉากหลัง
- วางตามภาพผังที่แนบ: เท้า/ที่นั่ง/เข่า แตะเส้น y=1290 ยอดหัวราว y 140–240
  ทะลุกรอบได้เฉพาะโซนเขียว (บน) และโซนน้ำเงิน (ข้าง) ห้ามวาดเส้นผังลงในภาพ

[ท่า]
ท่าบอกบทบาทในศึก (บุก/แทงก์/ฮีล/ยั่ว/บัญชาการ/ระยะไกล) ยืน นั่ง คุกเข่าได้
หันตัวเฉียงไปทางขวาของภาพ มุมกล้องระดับสายตา

[4 สเตจ]
1 ชุดเต็ม · 2 ช่วงบนขาด เห็นอก · 3 เหลือชั้นใน · 4 ไม่เหลือผ้า ใช้มือ/อาวุธ/ขาบังเฉพาะอวัยวะเพศ
- ข้อห้าม 18+ มีข้อเดียว: ไม่เห็นอวัยวะเพศโดยตรง นอกนั้นจัดเต็มได้
- ทุกสเตจใช้ "สเตจ 1 ที่ผมอนุมัติ" เป็นต้นแบบเสมอ ไม่ใช่ภาพล่าสุด
- หน้า ผม เครา แผล อาวุธ และชุดที่ยังเหลือ ต้องเหมือนต้นแบบ เปลี่ยนได้แค่ท่าและสีหน้า
- ทำตารางเสื้อผ้าตอนสเตจ 1 ว่าแต่ละชิ้นหายสเตจไหน ชิ้นที่หายแล้วห้ามเหลือแม้แต่เศษ

[ก่อนส่งทุกภาพ ตรวจเอง]
ขนาด 1024×1536 / พื้นหลังโปร่งใสจริง / อยู่ในผัง / ไม่มีตัวหนังสือ / ดีไซน์ตรงต้นแบบ / ไม่มีผ้าที่ควรหาย

เข้าใจแล้วตอบสั้นๆ ว่า "พร้อม" แล้วรอใบสั่งตัวละคร
```

## ใบสั่ง: บิ๊กเบน (ส่งหลังจากมันตอบว่า "พร้อม")

```
ตัวละคร: บิ๊กเบน (Big Ben) ชายอายุ 42 หุ่นหมี (bear) ไหล่กว้าง อกหนาขนดก พุงนิดๆ
หน้า: ผมสั้นสีน้ำตาลเข้ม เครายาวเต็มหน้า คิ้วหนา สายตาเงียบแต่ดุ
นิสัย: พ่อพูดน้อย ใจดี เหลาตุ๊กตาไม้ให้ลูก ปกป้องคนข้างหลัง
อาชีพ: คนตัดไม้ / ช่างไม้  ·  บทบาท: แทงก์ (ผู้พิทักษ์)
อาวุธ: ขวานตัดไม้ใบคู่ ด้ามยาวพันหนัง ใบขวานมีผ้าเก่าผูกไว้
ชุดสเตจ 1: เสื้อเชิ้ตลายสก็อตแดงดำเก่าซีด พับแขน เปิดหน้า ทับเสื้อกล้ามสีขาวหม่น
  กางเกงยีนส์เก่า เข็มขัดหนัง ปลอกข้อมือหนัง รองเท้าบู๊ตทำงาน
ท่า: ยืนย่อตัวตั้งรับ ถือขวานขวางลำตัว หัวขวานยื่นออกซ้ายของภาพเล็กน้อย
เริ่มจากสเตจ 1 + ตารางเสื้อผ้า
```
