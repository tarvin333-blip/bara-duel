## ลำดับงาน
1. [x] ✅ **ลำดับเทิร์นบนจอ** — แถบลำดับคนเล่นถัดไปบนสุด · ศพศัตรูค้างในแถว (กันแถวหลังขยับ) ตีศพได้ · ศัตรูตัวใหญ่ (บอส) กินสองช่อง
2. [ ] **คำพูดตัวละคร (บับเบิล)** — ตอนหลงทาง/ใจแกร่ง/ปางตาย/คริ/เสื้อหลุด ตัวละครพูดเป็นบับเบิลเหนือหัว มีผลต่อเพื่อน
3. [ ] **นิสัยติดตัว (quirk) แบบได้-เสีย** — ได้หลังจบการสำรวจ สูงสุด 3 ดี 3 เสีย · ล็อกได้ · รักษาที่ "บ้านหมอยา" (อาคารใหม่)
4. [ ] **อุปกรณ์** — อาวุธ/ชุดเกราะอัปเกรดตามอาชีพที่ร้านตีเหล็ก + เครื่องประดับ 2 ช่อง (ของดรอปจากหีบ/บอส มีข้อเสียบางชิ้น)
5. [ ] **อาคารในค่ายอัปเกรดได้** — ใช้ของมีค่า (ตราผู้คุม/เศษความทรงจำ) ที่ได้จากดันเจี้ยน · ลดราคา เพิ่มช่อง ปลดล็อกบริการ
6. [ ] **บอร์ดภารกิจ** — ภารกิจต่อสัปดาห์: สำรวจ 90% / ล้างทุกห้องต่อสู้ / ล่าบอส / เก็บของ · ระดับความยากต่อเลเวลทีม · รางวัลระบุชัด
7. [ ] **ทางเดินแบบเลื่อนข้าง** — เดินในทางเดินทีละช่องแบบ side-scroll เห็นกับดัก/ของ/ศัตรูข้างหน้า · สอดแนม · ปลดกับดักด้วยนักซุ่ม
8. [ ] **แคมป์ตามอาชีพ** — แต่ละอาชีพมีท่าแคมป์ 2–3 ท่าของตัวเอง (ปลดล็อกตามเลเวล) + ฉาก 18+ แบบเดิม
9. [ ] **สรุปผลหลังภารกิจ** — หน้าจอสรุป: ของที่ได้ XP ระดับใหม่ quirk ใหม่ ความหลงลืม ผู้เสียชีวิต · ฮีโร่ระดับสูงไม่ยอมลงดันเจี้ยนระดับต่ำ
10. [ ] **โรค/บาดแผลถาวร** — ได้จากศัตรูบางตัว/curio รักษาที่หมอยา
11. [ ] **เสียงและบรรยากาศ** — เสียงพื้นหลังต่อพื้นที่ เสียงตี/คริ/ตายชัดขึ้น (สังเคราะห์ ไม่ใช้ไฟล์คนอื่น)
12. [x] ✅ **บทสอน (tutorial run)** — ด่านแรกบังคับพร้อมคำแนะนำทีละขั้น
13. [ ] **ศัตรูและบอสเพิ่ม** — ทุกพื้นที่มีศัตรู 5–6 แบบ + บอส 2 แบบ, ท่าพิเศษ (ดึงแถว ผลัก ตีเปลี่ยนแถว)
14. [ ] **ขัดเกลา UI** — แอนิเมชันเปลี่ยนหน้า ทูลทิปค้างกด ตัวเลขความเสียหายคาดการณ์ ลำดับความสำคัญสีสถานะ
