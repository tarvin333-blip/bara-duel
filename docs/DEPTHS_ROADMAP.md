# Bara Depths — แผนพัฒนา (รอบอัตโนมัติ)

บทบาท: ศิลปิน + นักเขียน + เกมดีไซเนอร์ · ใช้แนวคิดของเกมแนว gothic dungeon crawler / JRPG / visual novel ได้
แต่ภาพ ไอคอน ข้อความ ต้องเป็นของเราเอง หรือ asset ฟรีที่สัญญาอนุญาตชัดเจน (CC0 / CC-BY ใส่เครดิต) — ห้ามยกงานของเกมอื่นมา
ใช้ asset เก่าจาก Bara Duel ได้ทั้งหมด (art/, web/art/, cg, bg, บทพูดใน web/index.html)

ทุกรอบ: ทำ 1 ก้อนงานให้จบ → ทดสอบ (sim + screenshot แนวนอน/แนวตั้ง ไม่มี error) → ตรวจความสวยด้วยตาเอง → commit → push → ติ๊ก ✅
